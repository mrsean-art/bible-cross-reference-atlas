# 圣经神的话语 1.0｜彩虹交叉引用地图 v3

- 全圣经 66 卷导航。
- 彩虹颜色分类与示范连线。
- 点击书卷节点查看当前记录；点击连线查看关系细节。
- 搜索、筛选、导入 TSV/CSV/JSON 原始资料、导出当前记录。
- 导入资料保留为「原始资料（未分类）」，不会自动把所有呼应都宣称为已核实的释经结论。

## 如何载入全库
1. 打开 https://openbible.info/labs/cross-references/
2. 下载 cross-references.zip 并解压。
3. 在网页中点击「导入完整交叉引用 TSV／CSV／JSON」，选择其中的 cross_references.txt 或 TSV 文件。
4. 本页会把数据并入当前记录，双向等价关系会按无向边去重。
5. 可按经文、主题、关系类别查找并导出 JSON。

另可参考 https://github.com/neuu-org/bible-crossrefs-dataset ，该仓库自述整合 OpenBible 与 Treasury of Scripture Knowledge 两类来源，规模超过 110 万条边；使用前请查看仓库当前文件、方法和授权说明。

注意：本运行环境不能直接连上 GitHub 下载大文件，因此本 ZIP 不会虚称已包含数十万条全库数据。它提供全书地图和导入流程；载入外部资料后才能显示完整底库。示范连线不是完整底库。
